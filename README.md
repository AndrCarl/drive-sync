# Fileserver Drive Sync

Öffentliche Informationsseiten für eine private Google-OAuth-Anwendung zur Synchronisierung des eigenen Google Drive mit einem privaten Fileserver mittels rclone.

Diese Website führt keinen Dateiabgleich aus. Das Repository enthält ausschließlich öffentliche Website-Dateien. Keine Zugangsdaten, OAuth-Tokens, privaten Kontoadressen oder synchronisierten Dateien hier ablegen.
